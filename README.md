# 💪 Habit Tracker - Stay Fit Together

Aplikasi web untuk tracking habit fitness bersama pasangan. Battle setiap minggu untuk menjadi yang paling rajin olahraga! 🏆

## ✨ Features

- 🔐 **Login Sederhana** - Username only (agus & gendut)
- 🏃 **5 Aktivitas** - Lari, Gym, Pilates, Tennis, Berenang
- 📊 **Weekly Streak** - Track progress dari Senin - Minggu
- 🏆 **Leaderboard** - Battle dengan emoji trophy/poop
- 📱 **Mobile First** - Optimized untuk smartphone
- 🌙 **Dark Mode** - Modern minimalist design
- ⚡ **Real-time** - Update langsung tanpa refresh

## 🚀 Quick Start

### 1. Install Dependencies
```bash
cd life-tracker
npm install
```

### 2. Setup Supabase Database

Buat tables berikut di Supabase:

```sql
-- Table Users
create table public.mst_users (
  id uuid not null default gen_random_uuid (),
  created_at timestamp with time zone not null default now(),
  name character varying not null,
  constraint users_pkey primary key (id)
);

-- Table Daily Logs
create table public.mst_daily_logs (
  id bigint generated by default as identity not null,
  created_at timestamp with time zone not null default now(),
  date date null,
  activity text[] null,
  user_id uuid null,
  constraint mst_daily_logs_pkey primary key (id),
  constraint unique_user_date unique (user_id, date),
  constraint mst_daily_logs_user_id_fkey foreign key (user_id) references mst_users (id)
);

-- Insert Users
INSERT INTO public.mst_users (id, name) VALUES 
  ('00000000-0000-0000-0000-000000000001', 'agus'),
  ('00000000-0000-0000-0000-000000000002', 'gendut');
```

### 3. Configure Environment

Edit file `.env.local` dengan credentials Supabase:

```env
NEXT_PUBLIC_SUPABASE_URL=your_supabase_project_url
NEXT_PUBLIC_SUPABASE_ANON_KEY=your_supabase_anon_key
```

### 4. Run Development Server
```bash
npm run dev
```

Buka [http://localhost:3000](http://localhost:3000) 🎉

## 📖 How to Use

1. **Pilih User** - Klik avatar Agus atau Gendut di halaman login
2. **Log Aktivitas** - Tap tombol aktivitas yang sudah dilakukan hari ini
3. **Track Progress** - Lihat streak mingguan di dashboard
4. **Check Leaderboard** - Siapa yang menang minggu ini?
5. **Stay Consistent** - Streak reset setiap Senin!

## 🏗️ Tech Stack

- **Framework**: Next.js 16.2 (App Router)
- **Language**: TypeScript 5
- **Styling**: Tailwind CSS 4
- **Database**: Supabase (PostgreSQL)
- **State**: React Context API
- **Storage**: LocalStorage (session)

## 🎯 Edge Cases Handled

- ✅ Multiple activities per day (counted as 1 streak)
- ✅ Deselect activity (toggle off)
- ✅ Weekly reset (Monday start, Sunday end)
- ✅ Session persistence
- ✅ Real-time sync

- User IDs di database harus match dengan yang di AuthContext
- Streak dihitung per hari (min 1 activity = 1 streak)
- Leaderboard update real-time saat ada perubahan
- Session disimpan di localStorage browser
