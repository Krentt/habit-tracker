# Habit Tracker - Setup Guide

## 🚀 Cara Menjalankan Project

### 1. Install Dependencies
```bash
npm install
```

### 2. Setup Supabase

#### Buat Database Tables di Supabase:

**Table: mst_users**
```sql
create table public.mst_users (
  id uuid not null default gen_random_uuid (),
  created_at timestamp with time zone not null default now(),
  name character varying not null,
  constraint users_pkey primary key (id)
);
```

**Table: mst_daily_logs**
```sql
create table public.mst_daily_logs (
  id bigint generated by default as identity not null,
  created_at timestamp with time zone not null default now(),
  date date null,
  activity text[] null,
  user_id uuid null,
  constraint mst_daily_logs_pkey primary key (id),
  constraint unique_user_date unique (user_id, date),
  constraint mst_daily_logs_user_id_fkey foreign key (user_id) references mst_users (id)
);
```

#### Insert User Data:
```sql
-- Insert dua user
INSERT INTO public.mst_users (id, name) VALUES 
  ('00000000-0000-0000-0000-000000000001', 'agus'),
  ('00000000-0000-0000-0000-000000000002', 'gendut');
```

### 3. Setup Environment Variables

Buat file `.env.local` di root folder `life-tracker/` dengan isi:

```env
NEXT_PUBLIC_SUPABASE_URL=your_supabase_project_url
NEXT_PUBLIC_SUPABASE_ANON_KEY=your_supabase_anon_key
```

**Cara mendapatkan credentials:**
1. Buka Supabase Project Dashboard
2. Klik Settings → API
3. Copy `Project URL` untuk `NEXT_PUBLIC_SUPABASE_URL`
4. Copy `anon public` key untuk `NEXT_PUBLIC_SUPABASE_ANON_KEY`

### 4. Jalankan Development Server
```bash
npm run dev
```

Buka [http://localhost:3000](http://localhost:3000) di browser.

## 📱 Cara Menggunakan

1. **Login**: Pilih akun Agus atau Gendut
2. **Catat Aktivitas**: Klik tombol aktivitas yang sudah dilakukan hari ini
3. **Lihat Progress**: Cek streak mingguan dan leaderboard
4. **Battle**: Yang paling banyak aktivitas dalam seminggu menang! 🏆

## ✨ Fitur

- ✅ Login sederhana (username only)
- ✅ 5 jenis aktivitas: Lari, Gym, Pilates, Tennis, Berenang
- ✅ Streak tracking per minggu (Senin - Minggu)
- ✅ Leaderboard real-time dengan emoji winner/loser
- ✅ Tampilan modern dark mode
- ✅ Responsive mobile-first design

## 🎨 Tech Stack

- **Framework**: Next.js 16
- **Language**: TypeScript
- **Styling**: Tailwind CSS 4
- **Database**: Supabase
- **Deployment**: Vercel (recommended)

## 📝 Notes

- User IDs harus match dengan yang di database (id '1' untuk agus, '2' untuk gendut)
- Streak reset setiap Senin
- Satu hari bisa multiple activities, tapi dihitung 1 streak
- Session tersimpan di localStorage
